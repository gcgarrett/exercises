# firstFrost

Exercise to implement the `firstFrost` method that takes in two parameters, an array of temperatures and a number `drop`, and returns an array where each element is how many days you'd wait until it's at least `drop` degrees colder than that day. If that condition is not met, then `0` is the value for that index.

Exercise comes from [cassidoo's newsletter](https://buttondown.com/cassidoo), [issue #476](https://buttondown.com/cassidoo/archive/u1f3b9-to-take-a-fine-idea-and-make-something/)

## running
* Python: `python firstFrost.py`

## output
Prints the resulting array to the command line
